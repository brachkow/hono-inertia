# Hono + Vue on Node.js

A Hono app on Node.js that serves Vue pages through `@brachkow/hono-inertia`, with server-side rendering. It shows:

- Navigation between pages with Inertia's `Link`
- Shared props (`appName`) and page props
- Partial reloads of an `optional()` prop
- A `deferred()` prop that loads after the page renders
- A `merge()` prop that appends the next page of users
- A form validated with a Zod schema, with errors after a redirect and live validation with precognition
- A flash message after the redirect

The same pages exist in the other examples, and one Playwright suite in `e2e/` runs against all of them.

## Running it

From the repository root, install the dependencies and build the adapter, which the example links from `packages/hono-inertia/dist/`:

```bash
pnpm install
pnpm build
```

Then, in this folder:

```bash
pnpm dev
```

This starts Vite on http://localhost:3002. `@hono/vite-dev-server` runs the Hono app inside Vite, and pages render on the server in the same process.

For a production build:

```bash
pnpm build
pnpm start  # The Hono app on port 3002
```

The Hono server renders pages itself. `honoInertia()`'s `ssr` option hands `src/ssr.ts` to `inertia({ assets })`, so there is no separate SSR server to run.

## How it fits together

`pnpm build` runs `vite build`, which builds both environments in `vite.config.ts`. `honoInertia()` builds the client first:

1. `client` builds the browser bundle into `dist/client`. `honoInertia()` moves its manifest out of the public output, for the server build to read
2. `ssr` builds `src/main.ts`, together with the app, `src/ssr.ts` and the pages, into `dist/server`. `src/main.ts` starts the Node server and serves `dist/client/assets`

## Key files

- `src/server.ts` is the Hono app: `inertia({ assets })` with a cookie session, routes, and the form schema
- `src/main.ts` is the production entry: it serves the app and the client assets on Node
- `src/client.ts` boots Inertia in the browser
- `src/ssr.ts` renders a page to HTML. The adapter calls it for every initial visit, through the plugin's `ssr` option
- `src/Layout.vue` is the default layout with the navigation and the flash message
- `src/pages/` holds the page components that `render()` names
- `src/pages.gen.ts` is generated by `honoInertia()` from `src/pages/`. Pages import `PageProps` from it, which types their props from the routes in the server
- `vite.config.ts` holds the two build environments and the dev server
