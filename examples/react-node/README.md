# React and Node example

A Hono app on Node that serves React pages through `@brachkow/hono-inertia`, with server-side rendering. It covers:

- Client-side navigation with `Link`
- Shared props (`appName`)
- A merge prop with a "Load more" button
- An optional prop loaded by a partial reload
- A deferred prop
- A form validated with a Zod schema, with errors after a redirect and live validation with precognition
- A flash message carried across a redirect in the session

The repo's Playwright suite in `e2e/` runs against this example's production build and its Vite dev server.

## Develop

From the repository root, install the dependencies and build the adapter, which the example links from `packages/hono-inertia/dist/`:

```bash
pnpm install
pnpm build
```

Then, in this folder:

```bash
pnpm dev
```

Vite serves the client and runs the Hono app on http://localhost:3001. Pages render on the server in the same process, so edits to the SSR code reload without restarting anything.

## Build and run

```bash
pnpm build
pnpm start
```

`pnpm build` runs `vite build` once. It builds the browser bundle into `dist/client`, then the Hono server from `src/main.ts` into `dist/server`. The Hono server renders pages itself. `honoInertia()`'s `ssr` option hands `src/ssr.tsx` to `inertia({ assets })`, so there is no separate SSR server to run.

## Key files

- `vite.config.ts` sets up the client and server builds, runs Hono inside Vite in dev, and adds `honoInertia()`, which gives `src/server.ts` the asset tags, the version and the SSR entry
- `src/server.ts` is the Hono app: `inertia({ assets })` with a cookie session, the routes and the form schema
- `src/main.ts` is the production entry: it serves the app and the client assets on Node
- `src/client.tsx` boots Inertia in the browser
- `src/ssr.tsx` renders a page to HTML. The adapter calls it for every initial visit, through the plugin's `ssr` option
- `src/Layout.tsx` is the default layout with navigation and the flash message
- `src/pages/` holds the page components that the server names in `render()`
- `src/pages.gen.ts` is generated by `honoInertia()` from `src/pages/`. Pages import `PageProps` from it, which types their props from the routes in the server
