# Hono + Svelte on Node.js

A Hono app on Node.js that serves Svelte 5 pages through `@brachkow/hono-inertia`, with server-side rendering. It shows:

- Navigation between pages with Inertia's `Link`
- Shared props (`appName`) and page props
- Partial reloads of an `optional()` prop
- A `deferred()` prop that loads after the page renders
- A `merge()` prop that appends the next page of users
- A form with validation errors, and a flash message after the redirect

The same pages exist in the other examples, and one Playwright suite in `e2e/` runs against all of them.

## Running it

From the repository root, install dependencies once with `pnpm install`. Then, in this folder:

```bash
pnpm dev
```

This starts Vite on http://localhost:3004. `@hono/vite-dev-server` runs the Hono app inside Vite, and pages render on the server in the same process.

For a production build:

```bash
pnpm build
pnpm start  # The Hono app on port 3004
```

The Hono server renders pages itself. `src/server.ts` imports `src/ssr.ts` and passes it to the adapter as `ssr.render`, so there is no separate SSR server to run.

## How it fits together

`pnpm build` runs `vite build`, which builds both environments in `vite.config.ts`. `honoInertia()` builds the client first:

1. `client` builds the browser bundle into `dist/client`. `honoInertia()` moves its manifest out of the public output, for the server build to read
2. `ssr` builds `src/main.ts`, together with the app, `src/ssr.ts` and the pages, into `dist/server`. `src/main.ts` starts the Node server and serves `dist/client/assets`

## Key files

- `src/server.ts` is the Hono app: the `inertia()` middleware, routes, and the flash cookie
- `src/main.ts` is the production entry: it serves the app and the client assets on Node
- `src/client.ts` boots Inertia in the browser
- `src/ssr.ts` renders a page to HTML. `src/server.ts` calls it for every initial visit
- `src/Layout.svelte` is the default layout with the navigation and the flash message
- `src/pages/` holds the page components that `render()` names
- `src/pages.gen.ts` is generated by `honoInertia()` from `src/pages/`. Pages annotate `$props()` with `PageProps` from it, which types their props from the routes in the server
- `vite.config.ts` holds the two build environments and the dev server
